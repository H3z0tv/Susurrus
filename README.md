<h1 align="center">Susurrus Chat</h1>

<p align="center"><em>Your whispers as a modern messenger for World of Warcraft.</em></p>

Susurrus Chat replaces the stack of floating whisper tabs with one clean messenger window: every conversation in a list on the left, the chat on the right, with history, online status and unread badges built in. Whisper someone and it opens. Close it and it tucks away into a minimap button that shows how many messages are waiting.

### Features

- **One window for everything.** A contact list with search, pinned and drag-to-reorder contacts, and a full scrollback of each conversation.
- **Character and Battle.net friends.** Whispering from the friends list, a chat name or any right-click menu opens Susurrus Chat, for both kinds of friend.
- **Online status at a glance.** Status dots, availability and "last seen" info on every contact.
- **Unread badges and alerts.** Counts on the minimap button and the toggle icon, an unread divider in the transcript, optional sounds, and a "mark all read" button.
- **Modern chat bubbles.** Grouped messages, date separators, delivery status, reply quotes, emoji reactions and an emoji picker.
- **Quick replies and drafts.** Save canned replies for busy moments. Half-written messages are kept per conversation.
- **Filters.** An ignore list plus keyword rules to cut spam and duplicate messages.
- **Themes.** Several looks, from native WoW to dark and warm styles, plus window scale and opacity.
- **Minimize to the minimap.** One click tucks the window away. Left-click the minimap button to bring it back.
- **Localized.** Ships with translations for 10 languages besides English.

### Install

1. Download the latest release.
2. Extract the `Susurrus` folder into `World of Warcraft/_retail_/Interface/AddOns/`.
3. Start the game, or `/reload` if it is already running.

### Usage

| Action | How |
| --- | --- |
| Open or close the window | Left-click the minimap button, press `CTRL-O`, or type `/susurrus` |
| Start a conversation | Whisper someone from the friends list, a chat name or a menu |
| Reply to the last whisper | `/wr` |
| Change the keybinding | Options > Keybindings > Susurrus |
| Open settings | The cog in the title bar |

### Compatibility

Built for retail World of Warcraft: Midnight (interface 12.0.5).
