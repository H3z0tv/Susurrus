# Susurrus Chat

Your whispers as a modern messenger for World of Warcraft. Works on Retail (Midnight), WoW Forever, Classic Era / Season of Discovery / Hardcore, TBC Anniversary, Titan Reforged, Cataclysm Classic and Mists of Pandaria Classic.
One window with history, online status and unread badges.

## Install
Copy the Susurrus folder into the Interface/AddOns/ folder of your game version (_retail_, _classic_, _classic_era_ and so on) and /reload. One download works on all of them.

## Use
- Moving chats between game versions: Settings > General > Sync Between Game Versions. Export History on one version, paste the text into Import History on the other
- Minimap button: left-click opens, shows unread count
- Whispering someone from the friends list, a chat name or a menu opens Susurrus
- Keybinding: Options > Keybindings > Susurrus (default CTRL-O)
